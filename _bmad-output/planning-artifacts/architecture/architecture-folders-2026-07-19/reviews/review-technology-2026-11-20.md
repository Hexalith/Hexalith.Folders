# Technology and brownfield-reality review · November 20, 2026

**Verdict: FAIL.** Two high-severity instructions in the canonical integration guidance would put independent clients on different APIs and publishers on topics the normal worker does not consume. The newer release posture and package inventory are consistent with their cited evidence. This review assessed the whole architecture against the Folders working tree at parent revision `b4c6b9a4` and the refreshed direct reference checkouts.

## High findings

1. **The canonical lifecycle diagram sends SDK and direct REST callers to the EventStore command endpoint.** The integration text at `architecture.md:1632` and the diagram beginning at `architecture.md:1646` put direct REST, SDK, CLI and MCP on `POST /api/v1/commands`. A-11 and A-12 specify distinct entry points. The generated client actually calls Folders resources, including `api/v2/folders` and its lifecycle-status route, at `src/Hexalith.Folders.Client/Generated/HexalithFoldersClient.g.cs:1490` and `:1659`. The owner OpenAPI declares these paths at `src/Hexalith.Folders.Contracts/openapi/hexalith.folders.v2.yaml:154` and `:459`. The native gateway command API also exists: `src/Hexalith.Folders.Server/Authentication/FoldersGatewayHumanBearerHandler.cs:34` distinguishes its own outgoing requests. The diagram conflates this internal/native interface with the external product contract. **Amend the integration text and diagram** to show REST/SDK → versioned Folders routes and eligible McpCli CLI/MCP → Gateway → Folders domain. Identify the frozen wrappers separately and keep route activation subject to the recorded A-11 controls.

2. **Two documented subscription names disagree with the shipped publishers and subscribers.** The topic rules at `architecture.md:923` and `:924` and the delivery graph at `:1634`, `:1635` and `:1659` prescribe per-tenant folder topics and `system.tenants.events`. The local AppHost applies the fixed `folders.events` override at `src/Hexalith.Folders.AppHost/Program.cs:81`–`:87`. The production binding explicitly describes and sets the override at `deploy/dapr/production/sidecar-config-bindings.yaml:16`–`:25`. The worker topic constant is `folders.events` at `src/Hexalith.Folders.Workers/SemanticIndexing/FoldersSemanticIndexingDefaults.cs:16`. The tenant event topic constant is `tenants.events` at `src/Hexalith.Folders/Projections/TenantAccess/FoldersTenantEventSubscription.cs:11`, and the production subscriber allowlist includes the two fixed names at `deploy/dapr/production/pubsub.workers.yaml:21`. A producer following the documented convention can publish into an unconsumed stream. **Name both fixed topic bindings**, distinguish the platform default from the Folders override, and retain tenant identity in each envelope and read-model partition. The semantic indexing consumer passes the envelope tenant and sequence to the process manager at `src/Hexalith.Folders.Workers/SemanticIndexing/FoldersSemanticIndexingEventProcessor.cs:67`.

## Medium findings

3. **D-6 describes the wrong platform snapshot interval.** The text at `architecture.md:608` states that the SnapshotManager default is 50 events. The referenced EventStore implementation defaults to 100, exposes domain and tenant/domain overrides, and documents their precedence at `references/Hexalith.EventStore/src/Hexalith.EventStore.Server/Configuration/SnapshotOptions.cs:27`–`:41`. The fallback returns that option at `references/Hexalith.EventStore/src/Hexalith.EventStore.Server/Events/SnapshotManager.cs:576`. No corresponding 50-event Folders override was found in `src/` or `deploy/`. **Correct the baseline to the configured platform value**, or record 50 explicitly as a distinct intended Folders override with an owner and a verification point.

4. **The deployment inventory names the wrong EventStore image repository.** The as-built component boundary at `architecture.md:1563` correctly gives `ContainerRepository=eventstore`. Deployment Instructions at `architecture.md:1718` instead name `hexalith-folders-eventstore`. The module host sets `eventstore` at `src/Hexalith.Folders.EventStore/Hexalith.Folders.EventStore.csproj:6`. An operator resolving the architecture name alone cannot establish the expected image identity. **Use the project’s repository name and the retained immutable image identity for the deployment attempt**, with any environment-specific registry mapping explicitly recorded.
