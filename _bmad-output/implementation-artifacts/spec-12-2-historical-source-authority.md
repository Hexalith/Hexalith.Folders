## Intent

Historical nonterminal/native-release/failed tasks can accept a rolled-back coherent derived triple; expired identity receipts cannot detect cross-position MessageId reuse. Implement and qualify bounded EventStore source authority, then consume it in Folders for both defects.

The owner-selected design is an additive authenticated native streaming scan with bounded pages, contiguous digest verification and equal initial/final current observations. A fresh domain fold selects the requested historical view or candidate message disposition; only the verified result is released. Exact Server/Workers enrollment authorizes this operation without widening ordinary metadata reads.
